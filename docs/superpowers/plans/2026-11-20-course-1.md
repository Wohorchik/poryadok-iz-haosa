# Учебный режим: новый стиль и курс 1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переделать учебный режим в новом тёмном стиле (палитра «синий и малиновый», 3D-картинки из Blender) и полностью наполнить курс 1 «Описательная статистика» четырьмя уроками с учебными виджетами.

**Architecture:** Новый учебный режим живёт в отдельной папке `src/course/`: чистая математика и хранение прогресса (с тестами), данные курсов, страницы (каталог, урок, итог курса), четыре виджета и свои стили. `App.tsx` для маршрутов `#study…` рендерит `CourseApp` вместо старого `CourseLibrary`. 3D-картинки рендерятся скриптами Blender из `tools/render/` в `src/course/art/` и попадают в единый файл сборки как data URI.

**Tech Stack:** React 19, TypeScript, Vite + vite-plugin-singlefile, Vitest, Blender 5.3 (Cycles, OptiX) + Python/Pillow для конвертации в WebP.

**Spec:** `docs/superpowers/specs/2026-11-20-courses-redesign-design.md`

## Global Constraints

- Сборка — один файл `dist/index.html`, работает без интернета. Никаких CDN и внешних шрифтов.
- Без новых npm-зависимостей. Формулы — HTML с Unicode и `<sub>`/`<sup>`.
- Палитра: фон `#000000`, карточка `#1c1c1f`, приподнятый слой `#26262b`, линия `#2e2e34`, текст `#ffffff`, вторичный текст `#a1a1aa`, акцент/выборка `#4a5cff`, акцент для мелкого текста `#8290ff`, теория `#ff4fc8`, верно `#5fd38d`, неверно `#ff6b6b`.
- Шрифты: заголовки Sofia Sans Extra Condensed 800 капсом; текст Golos Text; числа — моноширинный (`Consolas, 'Courier New', monospace`).
- Отступы 4/8/12/16/24/32/48/64/96; скругления 12/16/24/32. Фокус: `outline: 3px solid #8290ff; outline-offset: 3px`.
- Контраст текста ≥ 4,5:1, крупного текста и элементов ≥ 3:1. Мобильная ширина: поля 16 px, без горизонтальной прокрутки страницы.
- `prefers-reduced-motion: reduce` — никаких покачиваний, вместо видео статичный кадр.
- Префикс хранения прогресса: `matstat-course-v2/`.
- Маршруты: `#study`, `#study/<courseId>/<lessonId>`, `#study/descriptive/summary`, `#study/research` (старый модуль исследования, не трогаем).
- Бюджет графики учебного режима — до 4 МБ суммарно в `src/course/art/`.
- Эксперименты (`src/experiments/*`) не меняются. Модуль исследования меняется только цветами.
- Коммиты не делаем: пользователь коммитит сам. В рабочем дереве уже есть чужие незакоммиченные изменения — их не трогаем.

  - `rangeOf(values: readonly number[]): number`
  - `stretch(values: readonly number[], k: number): number[]` — x̄ + k(xᵢ − x̄).
  - `SPREAD_BASE = [2, 5, 7, 8, 13]`
  - `outlierRow(n: number, shift: number): number[]` — n значений по возрастанию от 40 до 60 (`40 + round(20·i/(n−1))`), к последнему прибавлен `shift`.
  - Вопросы: `frequencyQuestion(seed: number, thrown: number, bin: number): QuizQuestion | null`, `centerQuestion(values: readonly number[]): QuizQuestion`, `SPREAD_QUESTION: QuizQuestion`, `outlierQuestion(n: number): QuizQuestion`, `SUMMARY_QUESTIONS: QuizQuestion[]` (4 вопроса, по одному на урок).

  it('воспроизводим и префиксно устойчив', () => {

describe('frequencyTable', () => {
  it('частоты в сумме дают N, доли — 1', () => {

    expect(t.shares.reduce((a, b) => a + b, 0)).toBeCloseTo(1);
  });

    expect(rangeOf(stretch(SPREAD_BASE, 0.5))).toBeCloseTo(5.5);
