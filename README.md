# Порядок из хаоса

Веб-приложение с тремя опытами: скрытая картинка, треугольник Серпинского и доска Гальтона. Все вычисления выполняются в браузере.

## Запуск на защите

Откройте файл `dist/index.html` двойным щелчком. Интернет и установка не нужны.

## Разработка

```
npm install
npm run dev
```

## Проверка и сборка

```
npm test
npm run build
```

Сборка создаёт один файл `dist/index.html`, в который встроены код, стили и шрифты.
